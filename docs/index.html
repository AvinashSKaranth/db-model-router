Zero Trust Security

Built-In Security & Zero Vulnerabilities

Engineered for regulated environments (HIPAA, PCI-DSS, GDPR). Every release undergoes automated vulnerability auditing and SonarJS static code analysis.

🛡️

0 Vulnerabilities / 0 CVEs

Continuous audit through npm audit across all dependencies. Zero critical, zero high, zero moderate, and zero low vulnerabilities.

🔒

SQL Injection Immunity

Every SQL adapter utilizes parameterized bindings exclusively ($1, ?, :p). Table and column identifiers undergo strict character-set escaping.

🔑

AES-256-GCM Field Encryption

Transparent column and nested JSON key encryption with random 12-byte IVs, 16-byte authentication tags, and zero-downtime key rotation envelopes (enc:v1:...).

⏱️

Timing-Safe Authentication

Password hashing powered by crypto.scrypt and verified using crypto.timingSafeEqual to prevent timing attacks.

🛡️

ReDoS & Prototype Hardening

Regular expressions are bounded against catastrophic backtracking, and JSON payloads avoid prototype pollution via safe property copying.

📊

Grade A+ Quality Score (99%)

Zero ESLint errors, zero SonarJS code smells, and over 630 automated unit & property-based tests verifying deterministic behavior.

Enterprise Architecture

Everything You Need for Production

From multi-tenant SaaS backends to real-time event distribution and zero-downtime migrations.

🏢 Multi-Tenant SaaS Architecture

Turnkey SaaS backend generated automatically: tenants, users, roles, permissions, webhooks, and audit logs. Includes tenant isolation middleware and RBAC permission checks.

// Middleware isolates data per tenant automatically app.use(authenticate); app.use(tenantIsolation); app.use(hasPermission("users.read"));

🔐 Field-Level Encryption & Rotation

Mark any column as encrypted in your schema. Data is encrypted transparently on write and decrypted on read. Supports key rotation without downtime.

"columns": { "ssn": "encrypted|required|string", "salary": "encrypted|numeric", "profile.dob": "encrypted|datetime" }

📡 Real-Time Kafka CDC Events

Every insert, update, upsert, and delete publishes structured Change Data Capture (CDC) events to Kafka topics (e.g. dbmr.users) with batching.

{ "table_name": "users", "operation_type": "insert", "data": { "id": 1, "name": "Alice" }, "timestamp": "2026-11-07T12:00:00Z" }

⚡ Cross-Model ACID Transactions

Execute multi-model atomic operations with automatic rollback and nested savepoints. Kafka events are buffered and flushed only on successful commit.

await db.transaction(async (tx) => { const user = await tx.model(userModel).insert(uData); await accountModel.withTx(tx).insert({ user_id: user.id }); });

📖 Auto-Generated OpenAPI 3.0 & Docs

Full OpenAPI 3.0 specification generated from model metadata, complete with schemas, parameters, responses, and interactive Swagger UI mounted at /api-docs.

// Mounts interactive Swagger UI documentation app.use("/api-docs", swaggerUi.serve, swaggerUi.setup(spec));

🚀 Express & Ultimate-Express Support

Drop-in compatibility with standard Express or ultimate-express (powered by uWebSockets.js) for up to 6x higher HTTP request throughput.

// Automatically prefers ultimate-express when installed const express = require("ultimate-express"); const app = express();
Developer Tooling

The Unified CLI Toolchain

Single binary db-model-router that covers buildout, introspection, diagnostics, diffing, and key rotation.

db-model-router init
First-time project buildout: scaffolds models, routes, migrations, OpenAPI, and tests from schema.
db-model-router inspect
Introspects an existing live database schema and exports a clean dbmr.schema.json.
db-model-router doctor
Runs health checks: verifies schema validity, installed driver dependencies, and file sync.
db-model-router diff
Compares disk files against planned schema artifacts and outputs a visual unified diff.
db-model-router encrypt:scan
Scans database rows for unencrypted values and applies AES-256-GCM encryption in batches.
db-model-router encrypt:rotate-key
Rotates ciphertext from an older key version to the current active key with zero downtime.
db-model-router types
Generates strict TypeScript definitions (models.d.ts) matching model structures.
db-model-router db-manager
Launches a live browser-based database management interface for running queries and inspections.
